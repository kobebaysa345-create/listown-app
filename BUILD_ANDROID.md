# Build and download the LISTOWN Android app

This repository contains Flutter source code. The Android platform folder is generated by the included GitHub Actions workflow, which then builds a release APK.

## Build the APK with GitHub Actions

1. Create a repository on GitHub (for example, `listown-app`).
2. Upload the **contents** of this `listown` folder to the repository root. Keep the hidden `.github/workflows/build-android-apk.yml` file; the workflow is what builds the APK.
3. Open the repository's **Actions** tab and select **Build LISTOWN Android APK**.
4. Click **Run workflow** if no run has started automatically after pushing to `main` or `master`.
5. Open the completed run. Under **Artifacts**, download `LISTOWN-Android-APK`. The artifact is configured as the APK file itself, not the source ZIP.
6. Transfer/download the APK to your Android phone, open it, and follow Android's prompts to install it. Android may ask you to allow installation from the browser or file manager you used to download it. Only install APKs you trust.

If the run fails, open the failed workflow step and inspect its log. The APK is only available after the build job succeeds.

## Build locally instead

If Flutter and the Android toolchain are installed on your computer, run these commands from this project directory:

```bash
flutter create --platforms=android --org com.listown --project-name listown .
flutter pub get
flutter build apk --release
```

The APK should be created at:

`build/app/outputs/flutter-apk/app-release.apk`

The generated release APK is intended for direct testing/installation. Publishing to Google Play requires additional release preparation and signing configuration.
